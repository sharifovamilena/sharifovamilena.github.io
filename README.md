# Милена Шарифова - портфолио

Сайт: **https://sharifovamilena.github.io/**

Обычная статика: четыре HTML-страницы, один CSS, один JS. Сборки нет -
правишь файл, через минуту он на сайте.

```
index.html        главная - проекты, услуги, о себе, ставки, контакты
risky.html        Проект 01 - RISKY, AI-кампания в бьюти
slurp.html        Проект 02 - Slurp Laboratories, бренд-мир и ивент
hydromer.html     Проект 03 - Hydromer, сияющий уходовый мист
styles.css        все стили
script.js         анимации появления, меню, пауза видео за экраном
images/           13 фотографий в WebP
media/            2 лупа в MP4 + WebM с кадрами-постерами
og-image.jpg      превью для соцсетей, 1200x630
favicon.svg  sitemap.xml  robots.txt
```

## Как это устроено

**Шрифт - Inter.** В Archivo и Archivo Black, которыми набрана английская
версия, кириллицы нет вообще: заголовки отрисовались бы системным шрифтом.
Inter - такой же нейтральный плотный гротеск, но с нормальной кириллицей.
Заголовки идут в весе 900. JetBrains Mono в мелких подписях остался прежним.

**Названия проектов латиницей.** RISKY, Hydromer, Slurp Laboratories и
остальные - это имена, под которыми работы опубликованы на Behance.
Человек, который ищет "Slurp Laboratories", должен их найти. Всe вокруг
них по-русски, включая alt-тексты картинок.

**Типографика.** Везде "е" вместо "e" с точками, длинных тире нет -
только дефис с пробелами.

**SEO.** Свои title и description на каждой странице, lang="ru",
og:locale=ru_RU, разметка JSON-LD, sitemap.xml и robots.txt. Картинки
грузятся лениво, у каждой проставлены размеры.

## Что сделать после заливки

1. **Включить Pages.** Settings -> Pages -> Source: Deploy from a branch ->
   Branch main, папка / (root) -> Save.

2. **Яндекс.Вебмастер** - webmaster.yandex.ru. Добавить сайт, подтвердить
   права, отправить sitemap.xml. В России Яндекс - примерно половина поиска.

3. **Google Search Console** - тем же порядком, отдельным ресурсом.

4. **Поставить ссылку** в Telegram и в шапке Behance.
